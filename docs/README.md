# Docs

These pages live next to the code and change in the same pull requests, so
they describe what the repo actually does today. Diagrams are written in
Mermaid; GitHub draws them for you.

- [Architecture](architecture.md): what each piece does and how a request,
  a metric, a log line and a trace move through the system.
- [Run it locally](how-to/run-locally.md): the handful of commands you need
  day to day.
- [Endpoints and ports](reference/endpoints-and-ports.md): the lookup table.
- [Error budget policy](error-budget-policy.md): what happens when the SLO
  budget runs low.
